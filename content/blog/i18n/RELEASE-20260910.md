# Release acceptance: seven guides in ten languages

Scope: 63 new full translations of seven existing English guides. The English
library retains its 117 articles; the other 110 articles were not individually
rewritten or translated in this batch. The nine original evidence assets and
English source/publication-state files are unchanged.

## Editorial acceptance

The user explicitly accepted double agent review for this batch and production
after validation. Each author read the complete source, translated and
self-reviewed; a different agent read every complete translation and UI value,
requested corrections and verified their resolution. This is AI-assisted review,
not identified-human or native-speaker certification.

All three editorial reports are complete with no unresolved finding:

- `reviews/cross-review-fr-es-pt-BR.md`
- `reviews/cross-review-tr-id-fil.md`
- `reviews/cross-review-hi-bn-ar.md`

`translations/reviewed.json` records 63 reviewed and final hashes, nine reviewed
UI dictionaries, the English reference UI, separate author/reviewer identities
and the report fingerprints. The only subsequent Markdown change was the
mechanical `in_review` to `approved` status transition; all bodies are identical.
The independent `reviews/technical-release-review.md` verifies that transition
and the complete manifest. Manifest LF SHA-256:
`aa48eecd5969537519bfd61128972feef379d16c30f07d8e0304cd77a11f0ab9`.

## Technical and rendered acceptance

- Release rendered with Node 22.22.3, matching CI. Rebuilding `--existing-only`
  is idempotent: zero article pages updated and no publication-state change.
- Static release verifier: 70 selected article versions, ten language hubs,
  190 sitemap URLs, zero findings. Canonicals, reciprocal alternates, headings,
  internal anchors, original images, structured data, review hashes and robots
  states are checked.
- Local HTTP comparison: 190 pages, nine original evidence images, sitemap and
  robots, 201 checks, zero failures.
- Browser: all 70 approved versions checked at 1440 CSS pixels desktop and
  390 CSS pixels mobile. The source-connection guide was also checked in every
  language at 320 CSS pixels. No remaining text/viewport overflow was found.
- The ten hubs were inspected on mobile and desktop. The language picker
  navigated French to Hindi; its Escape key closes it and restores focus.
  A deliberate Hindi trial link opened the Hindi account page without submitting
  a form. French Support and its return link preserve `/blog/fr/`.
- Two long browser batches timed out during concurrent test load; unfinished
  checks were rerun in smaller batches. These are browser-emulation checks,
  not native phone/TV or accessibility-conformance acceptance.
- i18n validation passes: 7,233 messages across ten locales, 3,240 native entries.
  Native resources and clients are unchanged. The SPA runtime change is guarded
  to URL-owned static blog documents.

The independent technical review found and verified fixes for leftover preview
HTML, unreviewed UI-string changes, and the Support return locale. Parent runtime
checks also corrected the old offscreen skip link and fixed minimum body width
that caused RTL overflow. The existing dark/starfield visual system is preserved.

## Regression and release boundary

Before integrating the concurrent `5fca7579` main update, the complete Node 22
suite passed 4,044 tests, with ten skipped and zero failures (4,054 total).
The combined tree completed 4,069 tests: 4,058 passed, ten skipped, and one
existing time-sensitive complete-cache Gateway fixture failed under load.
That exact fixture then passed alone on the combined tree in 6.35 seconds.
No Gateway code/test was changed by this blog batch. The production workflow
must independently pass the complete suite; a local retry does not waive CI.

Both web publication paths rebuild the recorded releases, reject artifact
differences, reject unapproved extra HTML/hubs, validate all release/UI hashes
and run regression tests before Cloudflare deployment. No direct deployment
from the dirty original checkout is used.

Local acceptance is not a production or indexing receipt. The parent records
the pushed commit, CI deployment and public HTTP/browser verification separately
after the actual deployment. Publishing does not prove Google indexing, ranking,
tenfold traffic or commercial conversion. No Ads configuration, key-event
definition, account, provider connection or financial action is changed here.
